# Destroy it!

Roblox-симулятор руйнування. Підриваєш будівлі й паркани, гроші йдуть у сумку, продаєш їх на спавні й купуєш більшу сумку, сильнішу зброю та нові локації.

## Карта

```
          [1 Village] [3 Ranch]   [5 City]    [7 Military] [9 Laboratory]
[SPAWN]  ⚡⚡⚡⚡⚡⚡⚡⚡⚡⚡⚡ смуга швидкості ⚡⚡⚡⚡⚡⚡⚡⚡⚡⚡⚡⚡
[SHOP ]   [2 Farm]    [4 Suburbs] [6 Factory] [8 Castle]   [10 Spaceport]
[SELL ]
```

- Спавн, крамниця (SHOP) і продаж (SELL) стоять зліва.
- На дорозі персонаж бігає швидше.
- Локації 1→10 стають дорожчими зліва направо. Червона стіна відкривається за гроші, по черзі.
- У кожній локації є 4 будівлі (з вікнами й дверима) і паркан. Усе ламається по блоках і відбудовується через 30 секунд.
- Між будинками стоять червоні бочки **TNT**: підірвав одну, і пішла ланцюгова реакція.
- Зруйнував будівлю повністю, отримуєш бонус **BUILDING DESTROYED!**
- **Rebirth** у крамниці: скидає прогрес, зате гроші множаться (x2, x3, ...).
- У кожній локації є **особлива будівля**: млин, силос, водонапірна вежа, будинок зі скатним дахом, хмарочос, завод із трубами, танк, замкова вежа, купол лабораторії, ракета. За неї бонус подвійний.
- **Квести**: завжди 3 активні (зламати блоки, підірвати бочки, зруйнувати будівлі, продати на суму). Нагорода йде одразу на баланс.
- **Подарунки за час у грі**: на 5, 15 і 30 хвилині, таймер видно зліва.
- **Щоденна нагорода**: що більше днів поспіль, то більша (до 7 днів).
- **Бонус за друзів**: +10% грошей за кожного друга на сервері (до +50%).

Усі нагороди ростуть разом із прогресом: що дальшу локацію відкрито, то вони більші.

## Стиль

Яскравий пластик із пухирцями зверху, як у конструкторі. Тряска камери від вибухів, «+$» над місцем вибуху, уламки-цеглинки розлітаються.

## Керування

- **Клік / тап** кидає вибухівку в точку.
- **1–4** або кнопки внизу перемикають куплену зброю.
- Біля SHOP натисни **E**, щоб відкрити крамницю.
- Стань на зелений **SELL**, щоб продати вміст сумки.

## Таблиця лідерів

Біля спавну стоїть дошка **MOST DESTROYED** з топ-10 гравців за кількістю зламаних блоків, оновлюється раз на хвилину. Коли DataStore доступний, топ глобальний (усі сервери), інакше показує гравців поточного сервера.

## Robux (вкладка 💎 у крамниці)

| Що | Тип | Куди вставити ID |
|---|---|---|
| ⚡ Auto-Sell: гроші одразу на баланс | Gamepass | `Config.AUTO_SELL_PASS_ID` |
| 💰 x2 Money назавжди | Gamepass | `Config.X2_PASS_ID` |
| 💵 Money Pack / Huge Money Pack | Developer Product | `Config.PRODUCTS[1].id`, `[2].id` |
| 🔁 Instant Rebirth | Developer Product | `Config.PRODUCTS[3].id` |

Як створити:
1. Опублікуй гру.
2. На create.roblox.com відкрий свою гру → **Monetization**.
3. **Passes**: створи Auto-Sell і x2 Money. **Developer Products**: створи 3 продукти. Постав ціни.
4. Скопіюй ID у `src/shared/Config.luau`.

Поки ID = 0, кнопка пише «Not set up yet». Покупки продуктів обробляються безпечно: якщо гравець вийде або збереження не вдасться, Roblox повторить видачу, і двічі нічого не нарахується.

## Адмін-команди (для тестування)

Працюють у Studio, для автора гри та для UserId зі списку `Config.ADMINS`. Пиши в чат:

| Команда | Що робить |
|---|---|
| `!money 100000` | дати гроші (без числа: 100 000) |
| `!unlock` | відкрити всі локації |
| `!weapons` | дати всю зброю |
| `!bag` | найбільша сумка |
| `!autosell` | увімкнути/вимкнути Auto-Sell без покупки |
| `!x2` | увімкнути/вимкнути x2 Money без покупки |
| `!reset` | скинути прогрес до нуля |

## Як запустити

Потрібен [Rojo](https://rojo.space/docs/v7/getting-started/installation/) (CLI + плагін для Roblox Studio).

**Варіант 1: зібрати файл місця**
```
cd destroy-it
rojo build -o DestroyIt.rbxlx
```
Відкрий `DestroyIt.rbxlx` у Roblox Studio і натисни Play.

**Варіант 2: живий sync**
```
cd destroy-it
rojo serve
```
У Studio відкрий порожнє місце (Baseplate), у плагіні Rojo натисни Connect, потім Play.

## Збереження

Прогрес зберігається в DataStore: при виході, раз на хвилину і при вимкненні сервера. Щоб це працювало в Studio, опублікуй місце і ввімкни **Game Settings → Security → Enable Studio Access to API Services**. Без цього гра працює, але пише «Progress will not save this session».
